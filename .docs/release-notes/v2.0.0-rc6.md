# DNN Manager 2.0.0-rc6

**Your DNN folders on macOS and Linux.** Without IIS, the Projects page now lists the DNN sites in your projects
folder, New project can no longer be started while something else runs, and every password box can show what you
typed. This is a release candidate: try it next to your current version before 2.0.0.

## Highlights

### Projects on macOS and Linux
- **Projects** lists every folder in your projects folder that holds a DNN install (`bin/DotNetNuke.dll`), with its
  DNN version and database. They show as **Folder - no IIS**: there is no website to start or stop.
- The projects folder is `DNN` in your home folder (`/Users/you/DNN`, `/home/you/DNN`) unless you choose another in
  **Settings → Projects**. On Windows it stays `C:\DNN`.
- The DNN version of a site is now read on macOS and Linux too.

### New project waits for its turn
- While a project is being made - or any other operation runs - **New project** is dimmed and can't be used. A note
  above it says what is running; the page opens again when that is done.
- **Tab** passes over the locked page, so the keyboard goes on to the rest of the window.
- On macOS and Linux the page stays locked: making or importing a project needs IIS.

### Show the password
- Every password box has an eye button that shows and hides what you typed - also the host, SA and database server
  passwords in **Settings**.

## Other changes
- The **?** in the title bar's help button is a little smaller inside its ring.
- The icon of the projects list's **Columns** button is larger.

## Upgrading
Install the new package over the old one: the .msi on Windows, the .dmg on macOS, the .deb on Linux. Your settings
keep their format.
- This is a pre-release: **Check for Updates…** doesn't offer it - download it from this release's page.
- On macOS and Linux, if you set the projects folder to `C:\DNN` before, choose your DNN folder in
  **Settings → Projects**.
