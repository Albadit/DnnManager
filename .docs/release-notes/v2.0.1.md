# DNN Manager 2.0.1

**Servers in Settings, a roomier diff.** Manage Source Control's servers in one place and bring them in from
FileZilla, compare long lines side by side, and find the project and server you chose last still chosen.

## Highlights

### Servers in Settings
- **Settings → Servers** lists every Source Control server - name, protocol, user, host, port and folder.
- **Add server…**, **Edit…** and the bin act at once, without **Save**. Deleting a server asks first and leaves
  the server itself untouched.
- **Import…** adds the sites of a FileZilla Site Manager file (FileZilla's **File → Export…**, or its
  `sitemanager.xml`), folders included. A server you already have is left as it is. Sites that can't be used, such
  as implicit FTP over TLS, are left out and named in the message.
- **Export…** writes every server to a file FileZilla can import. You choose **Without passwords** or **With
  passwords**. With passwords, anyone who has the file can read them.

### A roomier diff
- Drag the line between the two halves to make one wider.
- A long line scrolls sideways - Shift+wheel, a touchpad, or the scroll bar under a half - and both halves move
  together.
- The file's actions (**Merge…**, **Keep mine**, **Keep the server's**, **Download**, **Delete on server…**) and
  the ↑ ↓ change buttons are on the right of the tabs, as in VS Code. Changes go to the server with Stage and
  **Commit**.

### Your choices remembered
- Source Control chooses the project and server you picked last when it opens, as long as they still exist.

## Other changes
- **Inline** is gone: the diff is always side by side.

## Upgrading
Install the new package over the old one: the .msi on Windows, the .dmg on macOS, the .deb on Linux. Your settings
keep their format.
