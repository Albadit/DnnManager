# DNN Manager 2.0.0-rc2

**DNN Manager, rebuilt and installable everywhere.** The whole app is rewritten in Rust with the pages and actions
you know from 1.8.7, and every release now comes as an installer for Windows, macOS and Linux. This is a release
candidate: try it next to your current version before 2.0.0.

## Highlights

### The app you know, rebuilt
- **Projects**, a project's details, **New project**, **Settings** and **Troubleshoot** work as in 1.8.7: start, stop
  and restart sites, keep them warm, clone, back up, restore, upgrade DNN, rename, edit host names and app pools,
  change the database connection, and remove a site.
- The bottom panel keeps **Output**, **Logs** and **Terminal**; the command palette (**Ctrl+Shift+P**), the guided
  tour and **Help** (**F1**) are there too.
- Settings → **Keyboard shortcuts** lets you change the shortcut of any command.

### An installer for every system
- Windows: `DnnManager-windows-x86_64.msi` and `DnnManager-windows-arm64.msi`.
- macOS: `DnnManager-macos-arm64.dmg` (Apple Silicon) and `DnnManager-macos-x86_64.dmg` (Intel) - open it and drag
  **DNN Manager** to Applications.
- Linux: `DnnManager-linux-amd64.deb` and `DnnManager-linux-arm64.deb` (also as `-x86_64.deb` and `-aarch64.deb`), for
  Ubuntu 22.04, Debian 12, Linux Mint 21 or newer. `apt` installs what it needs.
- IIS exists only on Windows: on macOS and Linux the app opens and says there are no websites to manage there.
- `SHA256SUMS.txt` lists each file's checksum. The installers aren't code-signed yet, so Windows and macOS ask before
  the first start.

### Your settings and projects carry over
- DNN Manager keeps using `Documents\DnnManager`: your settings, projects, kept DNN packages, backups and logs are
  where they were.

## Other changes
- **Check for Updates…** (the gear menu) tells you when a newer release is out; you install it by downloading its
  package from the release page.
- Esc closes a dialog from any of its fields; in a search box it first empties the search.

## Upgrading
This is a pre-release: **Check for Updates…** doesn't offer it - download it from this release's page.
- **Source Control** from 2.0.0-rc1 - with its Explorer, Search and tabs - isn't in this version. If you use it, keep
  2.0.0-rc1.
- On Windows the .msi installs into `Program Files\DNN Manager`, next to a DNN Manager installed with the earlier
  Setup (`Program Files\DnnManager`) rather than over it. Uninstall the old one in Windows' **Apps** settings if you
  want only this one. Only one of them runs at a time.
- DNN Manager no longer installs updates itself: install each new release's package over this one.
- If DNN Manager started when you sign in, turn **Start DNN Manager when you sign in to your computer** on again in
  **Settings → General**, so it starts this version.

## Tested
- All 819 automated tests pass on Windows. They cover every action against stand-ins for IIS, SQL Server and the
  files, so nothing on the PC changes while they run.
- Checked by hand on Windows 11 against a stand-in IIS: **Projects**, a project's details with its database read,
  **New project** with the DNN versions from GitHub, **Settings**, **Troubleshoot**, the menus, the tour, help and
  **Check for Updates…**. Reading a real IIS was checked once.
- The Windows x64 .msi was built and holds `DnnManager.exe` for `Program Files\DNN Manager`.
- Not checked yet - what this release candidate is for: actions that change a real site or database (create, clone,
  back up, restore, upgrade, rename, remove), the Windows ARM64 installer, and the macOS and Linux apps on a real Mac
  or Linux PC.
