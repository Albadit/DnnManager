# DNN Manager 2.0.2

**Updates with one click.** When a newer version is out, an **Update** button in the title bar installs it for you.
On Windows DNN Manager closes and opens again on the new version by itself.

## Highlights

### Update in the title bar
- While GitHub has a newer release, a blue **Update** button shows in the title bar, left of **?**.
- It downloads the package for your system and checks it against the SHA-256 GitHub lists. The download shows in
  **Output**, and **Cancel** stops it.
- On Windows DNN Manager then closes, the installer runs with its progress bar, and DNN Manager opens again by itself
  and tells you how the update went. If it fails, the old version stays.
- On macOS and Linux the downloaded .dmg or .deb opens for you to install.

## Other changes
- **Settings → About** and **Check for Updates** now say "Update in the title bar installs it" instead of pointing
  you to the release page.

## Upgrading
Install the new package over the old one: the .msi on Windows, the .dmg on macOS, the .deb on Linux. Your settings
keep their format.
- Install this version by hand once. From here on, **Update** installs the next ones.

## Tested
- On Windows with the .msi installed: a 2.0.0 build of this version showed **Update**, and clicking it downloaded the
  published 2.0.1 .msi, closed DNN Manager, installed 2.0.1 and started it again.
- All 976 automated tests pass on Windows, up from 973 in 2.0.1.
