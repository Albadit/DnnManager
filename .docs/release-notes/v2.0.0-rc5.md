# DNN Manager 2.0.0-rc5

**At home on macOS and Linux.** Shortcuts use ⌘ on a Mac, text fields edit the way your system's own do, and the
status bar shows real memory, processor and disk figures on every system. This is a release candidate: try it next
to your current version before 2.0.0.

## Highlights

### ⌘ shortcuts on macOS
- Every shortcut that takes **Ctrl** on Windows takes **⌘** on a Mac: **⌘B**, **⇧⌘P**, **⌘J**, **⌘,** and the
  others. **Ctrl+Tab** and **Ctrl+\`** stay **⌃**, because ⌘Tab and ⌘\` belong to macOS.
- The find bar's switches are **⌥⌘C**, **⌥⌘W** and **⌥⌘R**, so **⌥C** still types ç.
- Menus, tooltips and **Settings → Keyboard shortcuts** write the keys the way macOS does (**⇧⌘P**).
- DNN Manager has a menu bar on macOS: **⌘Q** quits, **⌘H** hides it, **⌘M** minimizes the window, and **Edit** has
  Undo, Cut, Copy, Paste and Select All.
- Tooltips show your own shortcut when you changed it in **Settings → Keyboard shortcuts**.

### Text fields that edit like your system's
- Copy, cut, paste, select all, undo and redo work in every text field: with **Ctrl** on Windows and Linux, with
  **⌘** on macOS. **Ctrl+Y** and **Ctrl+Shift+Z** both redo.
- Move and select a word at a time with **Ctrl+←** / **Ctrl+→** (**⌥←** / **⌥→** on macOS), and delete one with
  **Ctrl+Backspace** (**⌥⌫**). **Shift+Home** and **Shift+End** select to the start and end; on macOS **⌘←**,
  **⌘→**, **⌘⌫**, **⌃A** and **⌃E** work too.
- Double-click selects a word and triple-click the whole line. A drag keeps selecting when the mouse leaves the
  field.
- Right-click a text field for **Undo**, **Redo**, **Cut**, **Copy**, **Paste** and **Select all**.
- A text longer than its field scrolls, so you always see the cursor.

### Memory, processor and disk on macOS and Linux
- The status bar reads memory, processor use and the disk of your projects folder on macOS and Linux. Before, it
  showed 0 there.
- A figure that can't be read shows `--.--` instead of 0. Processor use appears two seconds after the start.

## Other changes
- In the terminal on macOS, **⌘C** copies and **⌘V** pastes; **⌃C** always stops the running program.
- In **Settings**, **⌘F** goes to the search on macOS.
- Fixed: on macOS, an empty text field could crash DNN Manager when macOS asked it about the text under the mouse
  (dictionary look-up and the like).

## Upgrading
Install the new package over the old one: the .msi on Windows, the .dmg on macOS, the .deb on Linux. Your settings
keep their format.
- This is a pre-release: **Check for Updates…** doesn't offer it - download it from this release's page.

- On Windows 11, against a stand-in IIS: typing and **Ctrl+A** with **Backspace** in the command palette; the status
