# DNN Manager 2.0.0-rc4

**Everything works from the keyboard.** You can now go through the whole window with Tab, open menus and dialogs and
come back from them without touching the mouse. The icons are drawn by DNN Manager itself, so they look the same on
every system. This is a release candidate: try it next to your current version before 2.0.0.

## Highlights

### Use DNN Manager without a mouse
- **Tab** and **Shift+Tab** go from control to control - the title bar, the activity bar, the page, the panel and
  the status bar - and **Enter** or **Space** presses the one with the blue ring. The ring shows only while you use
  the keyboard; a click hides it again.
- Menus - the gear, **?**, a project's **⋮** and the right-click menu - open on their first item: **Up** / **Down**
  move, **Enter** runs an item or opens its submenu, **Esc** closes the menu and puts you back on the button that
  opened it.
- **Settings**, dialogs and questions keep **Tab** inside them while they are open, and **Esc** takes you back to
  where you were.
- The projects list is one stop for **Tab**: **Up** / **Down** choose a project (a blue bar marks it), **Enter** opens
  it, and **Esc** brings you back to the same project in the list.
- In the terminal, **Tab** still goes to the shell; **Ctrl+J** leaves it.

### Icons that look the same everywhere
- Every icon is now drawn by DNN Manager instead of taken from Windows' icon font, so they look the same on
  Windows 10, Windows 11, macOS and Linux.
- The help icon (**?**) in the title bar is larger and easier to read, and a project's **⋮** now stands upright.
- All buttons are the same height, so **⋮** lines up with **Open folder** and the other buttons beside it.

## Other changes
- The two pickers in the **Logs** tab work like every other select: from the keyboard, with the logs grouped under
  headings.

## Upgrading
Install the new package over the old one: the .msi on Windows, the .dmg on macOS, the .deb on Linux. Your settings
keep their format.
- This is a pre-release: **Check for Updates…** doesn't offer it - download it from this release's page.
