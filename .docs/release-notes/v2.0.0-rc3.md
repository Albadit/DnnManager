# DNN Manager 2.0.0-rc3

**Opens on a Mac, with its icon on Windows.** The macOS app no longer says it is damaged, the Windows app shows the
DNN Manager icon everywhere, and lists and selects work from the keyboard. This is a release candidate: try it next
to your current version before 2.0.0.

## Highlights

### The Mac app opens
- A DNN Manager downloaded from this release no longer says it **"is damaged and can't be opened"**.
- The first time, macOS says it can't check DNN Manager: choose **Done**, then **System Settings → Privacy &
  Security → Open Anyway**. After that it opens as usual.

### The DNN Manager icon on Windows
- The window, the taskbar, the desktop shortcut and Explorer show the DNN Manager icon instead of Windows' blank
  program icon.

### Selects and lists from the keyboard
- In a select, **Up**, **Down**, **Home**, **End**, **Page Up** and **Page Down** move the highlight, **Enter** or
  **Space** chooses, and **Esc** closes the list without closing the dialog. The list opens on the current value and
  closes when you click outside it. This holds for every select, **Settings** included.
- Scroll bars can be dragged, or clicked beside the thumb to jump there; the thumb widens under the mouse.

## Other changes
- On Windows, **Browse…** for the **Site .zip** and the **Database .bacpac** in **New project**, and **Import…** in
  **Edit DNN upgrade path**, list only files of that type.
- With the side bar closed, the page keeps its gap next to the activity bar.

## Upgrading
Install the new package over the old one: the .msi on Windows, the .dmg on macOS, the .deb on Linux. Your settings
keep their format.
- This is a pre-release: **Check for Updates…** doesn't offer it - download it from this release's page.
- On a Mac where 2.0.0-rc2 was called damaged: drag this version to Applications over it and open it as above.

## Tested
- All 833 automated tests pass on Windows, up from 819; the build, the tests and clippy also pass on Linux and
  macOS.
- The Windows app was built and its icon read back from `DnnManager.exe`.
